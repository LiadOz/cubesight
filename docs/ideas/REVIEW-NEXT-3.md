Where a drill sets up a case (alg/OLL/PLL/F2L/cross/lookahead), the physical cube is generally NOT in that state, so make it explicit: either the virtual case (labelled "case") or the mirrored physical cube (labelled "your cube"), and use the guided setup (the guided-scramble engine) to bring the physical cube to the case when the drill needs it. Tests with the fake cube for mirroring + state equality.
2. **Examples animate FULL turns.** Alg playback, "better solution" replays, cross/lookahead plan playback and any demonstration animate complete quarter/half turns (smooth, readable speed). The partial "cue" stays only as the live hint for the next move the user must make in a guided scramble/recovery.
3. **Praise good play.** The coach/review must also call out what went well, not only mistakes: the optimal or near-optimal cross / X-cross, choosing the best available F2L pair (per the pair engine), an efficient pair (≤ the proven minimum + 1), a good pseudo pair, skips, a fast recognition, a clean LL. Positive markers on the ring, ranked alongside the negatives, in friendly cubing language (VOICE.md). Each must be evidence-based (proven/verified results only; no praise from partial searches unless labelled).
